# Sample interview questions (edit or replace this file)

The Demo mode's AI interviewer picks questions from the documents in this folder. A question is any line that ends with "?" or starts with a prompt such as "Tell me" or "Describe". Lines starting with "A:" are treated as answers and are never asked. Put your own question lists here as PDF, Word, text or Markdown files.

Q: Tell me about yourself.
A: I'm a computer science student who enjoys building practical projects. I've worked on a web app with a team, learned to debug and ship under deadlines, and I'm looking to grow in a role where I can keep learning.

Q: Why do you want this job?
A: The role matches the skills I've been building, and the team works on problems I find interesting. I want to contribute quickly and learn from experienced people.

Q: What are your strengths?
A: I learn quickly, I communicate clearly, and I finish what I start. For example, I picked up a new framework in two weeks to deliver a class project on time.

Q: What is your biggest weakness?
A: I used to take on too much myself. I now break work into smaller tasks, ask for help early, and set time limits so I don't over-polish.

Q: Describe a time you worked in a team.
A: In my final-year project, four of us built a web app. I handled the backend API, we agreed on tasks in weekly meetings, and we resolved a design disagreement by prototyping both options and testing them.

Q: How do you handle pressure and tight deadlines?
A: I list what must be done, tackle the highest-impact items first, communicate early if something is at risk, and avoid last-minute changes.

Q: What is a closure in JavaScript?
A: A closure is a function that remembers the variables from the scope where it was created, even after that scope has finished. It is used for private state, callbacks and factories.

Q: What is the difference between a process and a thread?
A: A process has its own memory space and resources, while threads inside a process share memory. Threads are lighter to create but need care with shared data.

Q: Explain what an API is.
A: An API is a defined way for programs to talk to each other, such as a web server exposing endpoints that return data to an app.

Q: Where do you see yourself in five years?
A: Growing into someone who owns features end to end and helps newer teammates, while deepening my technical skills.

Q: Tell me about a mistake you made and what you learned.
A: I once pushed a change without testing edge cases and it broke a page. I fixed it quickly, wrote tests for it, and now run a checklist before releasing.

Q: Do you have any questions for us?
A: Yes: what does success look like in the first six months, and how does the team handle code reviews and mentoring?
